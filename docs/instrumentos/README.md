# Instrumentos de coleta

A serem elaborados até 10/11/2026 (ver docs/tarefas.md):

- `questionario_estudantes`: diagnóstico curto de educação financeira (ensino médio), sem nome, matrícula ou idade exata.
- `roteiro_direcao`: atividades de educação financeira existentes e temas prioritários (direção e professores).
- `questionario_voluntarios`: estudantes de Economia da UFPB (semestre, horas semanais, interesse).
- `termo_autorizacao_responsaveis`: obrigatório para estudantes menores de idade.

Só versões sem dados pessoais devem entrar no repositório.
